# Games E-Store

A modern landing page for a fictional game store built with HTML, CSS, and Sass.

## Features

- Responsive one-page layout
- Hero banner and featured game cards
- Gallery and gamer sections
- Clean styling with Sass
- Ready for deployment on GitHub Pages

## Technologies Used

- HTML5
- CSS3
- Sass
- Gulp
- GitHub Pages

## Local Development

1. Install dependencies:
    ```bash
    npm install
    ```
2. Start the development server:
    ```bash
    npx gulp
    ```
3. Open the local preview in your browser.

## Deployment

This project is published on GitHub Pages:

- Live site: https://pafuluofu-dev.github.io/games-e-store/

## Project Structure

- src/ — source HTML, Sass, and assets
- dist/ — generated production files
- .github/workflows/ — GitHub Pages deployment workflow
